# プライバシーポリシー

Ryosuke Suzaki（以下「運営者」）は、カフェ向け業務アプリ「CafeKit」（以下「本アプリ」）における利用者の情報の取り扱いを、次のとおり定めます。

## 1. 取得する情報

| 区分 | 内容 |
| --- | --- |
| アカウント | メールアドレス、認証サービスが発行する利用者 ID |
| 店舗情報 | 店舗名、メールアドレス、電話番号 |
| スタッフ | 名前、雇用形態、時給などの契約条件、シフト、メモ |
| 仕入先 | 名称、メールアドレス、電話番号 |
| 業務データ | 商品・材料・作り方、売上、経費・固定費、廃棄、在庫・棚卸し、発注の履歴、予定 |
| 自由入力 | 発注の備考、予定・廃棄・スタッフのメモなど、利用者が入力した文章 |
| 画像・ファイル | 商品画像、読み取りのために選択した写真・ファイル |
| POS 連携 | スマレジの契約 ID、取引のデータ、取り込んだ売上の CSV |
| アクセスログ | サーバーへのリクエストの種類・結果・処理時間 |

## 2. 利用目的

- 本アプリの機能の提供（アカウントの認証、業務データの保存・集計、発注の目安の算出、発注メールの送信、ファイル・写真からの読み取り）
- 障害への対応と不正な利用の防止
- お問い合わせへの対応

取得した情報を、広告の配信や、他社のアプリ・ウェブサイトをまたいだ利用者の追跡には使いません。

## 3. 外部サービスへの送信

本アプリは、機能の提供のために次の外部サービスに情報を送信します。

| 送信先 | 送信する情報 | 目的 |
| --- | --- | --- |
| Google LLC（Firebase Authentication） | メールアドレス、パスワード | アカウントの認証 |
| Google LLC（Google Cloud） | 本アプリのサーバーが扱う情報 | サーバーの運用、データ・画像の保存 |
| OpenAI, L.L.C.（OpenAI API） | 読み取りのために選択した写真・ファイルの内容、照合に使う材料・発注の明細、売上の CSV の先頭の数行 | ファイル・写真からの読み取り |
| 株式会社スマレジ | スマレジの契約 ID | 連携した店舗の取引のデータの取得 |
| 【メール送信サービスの提供者】 | 発注メールの内容（発注先のメールアドレス、店舗名・連絡先、材料と数量、備考） | 発注メールの送信 |

## 4. 第三者への提供

法令に基づく場合を除き、利用者の同意なく情報を第三者に提供しません。

発注メールは、利用者の操作により、利用者が登録した発注先に送信されます。

## 5. 商品画像の公開範囲

商品画像は、画像の URL を知っていれば認証なしで閲覧できる場所に保存されます。URL は推測できない形式で発行し、保存されている画像の一覧は公開しません。

## 6. 保存期間と削除

- 情報は、利用者が退会するまで保存します。
- 退会すると、店舗のデータ、商品画像、認証サービスのアカウントを削除します。
- 退会後も、同じアカウントで店舗が作り直されないよう、利用者 ID と退会日時は保存します。
- アクセスログは、障害への対応に必要な期間保存します。

## 7. 開示・訂正・削除などの請求

利用者は、自身の情報の開示・訂正・削除などを、下記のお問い合わせ先に請求できます。本人であることを確認したうえで、法令に従って対応します。

## 8. 改定

本ポリシーを改定した場合は、このページで公表します。
